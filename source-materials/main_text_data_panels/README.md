# Main-Text Data Panels

This folder covers only the data-derived main-text panels requested for
source-data auditing:

`Fig. 2d-g`, `Fig. 3d-f`, and `Fig. 4g-i`.

It does not attempt to reproduce the complete manuscript figure layouts,
workflow schematics, system diagrams, or manually assembled Word/PDF figure
pages. The purpose is narrower: each listed panel is mapped to the included data
and regenerated as a standalone audit replot from the source materials package.

The generated PDF/PNG files are not exact visual copies of the final assembled
manuscript panels. The submitted main manuscript is authoritative for the final
visual appearance, panel assembly, labels, captions, and claims. These outputs
are provided to make the data and code path inspectable. Differences in crop,
color scale, font, normalization display, panel spacing, selected representative
channels, selected tasks, or plotting style should not be read as discrepancies
in the underlying data source.

## Contents

| Path | Role |
| --- | --- |
| `MAIN_TEXT_DATA_PANEL_SOURCE_MAP.tsv` | Panel-level mapping from main-text panel to data, script, output, and visual status. |
| `source_data/main_fig2_scaling_summary.json` | Compact scaling values used for Fig. 2f. |
| `scripts/generate_main_text_data_panels.py` | Recreates the ten standalone data panels. |
| `generated_panels/` | Output PDF/PNG panels generated by the script. |

## Reproduction

From the package root:

```bash
python main_text_data_panels/scripts/generate_main_text_data_panels.py
```

The script writes PDF and PNG outputs into
`main_text_data_panels/generated_panels/`.

## Panel Provenance Notes

The ten panels intentionally use selected data slices rather than every
measurement in the five report folders.

Fig. 2d-f use the first Result2 experiment. Fig. 2g uses the refined Result2
focusing experiment. Fig. 3d is the theory/simulation response-set panel,
Fig. 3e uses the measured Result3 response/TM column, and Fig. 3f uses the
Result3 measured-system operator metadata to compute theoretical reachable
intervals for the comparable-coherence nesting test. Fig. 4g and Fig. 4i come
from the first Result4 Complex-B report, while Fig. 4h follows the Result4
refine bin-10 Complex-B scatter logic.

## Scope Boundary

The panels generated here are data-panel reproductions, not exact reconstruction
of the full manuscript page layout. For example, Fig. 2a-c, Fig. 3a-c and
Fig. 4a-f contain overview, workflow, or schematic content and
are therefore outside this data-panel package.

Use `../SM_SCOPE_AND_RELATION_TO_MANUSCRIPT_SI.md` for the package-level
relationship between these audit replots, the formal SI, and the main
manuscript.
