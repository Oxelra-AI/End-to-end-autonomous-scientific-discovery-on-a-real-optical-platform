## Review Role

The video shows the live system interface, physical-instrument status indicators,
optical-power monitoring, SLM phase display, CMOS speckle/amplitude panels, and
a witness-camera view of the optical bench and operating computer.

This file is included as visual documentation that the study involved a real
optical experimental platform. It is not used as quantitative evidence for any
reported result. Quantitative reproducibility is supported by the raw data,
processed data, scripts, figures, report PDFs, and checksum manifests included
elsewhere in this package.
