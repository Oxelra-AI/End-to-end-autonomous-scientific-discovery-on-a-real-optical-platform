# Repository Deposit Notes

The full `SM_Source_Materials_CORE_5REPORTS/` archive is intended for public
repository deposition, not direct upload as a large journal SI file.

## Recommended Submission Route

Repository DOI: `10.5281/zenodo.19890402`

Repository URL: `https://doi.org/10.5281/zenodo.19890402`

1. Use the Zenodo record associated with the repository DOI above.
2. Keep the DOI fixed in the manuscript, SI, and source-data/code guide.
3. Upload `SM_Source_Materials_CORE_5REPORTS.tar.gz` and
   `SM_Source_Materials_CORE_5REPORTS.tar.gz.sha256` to the Zenodo record.
4. Confirm that the DOI in `DATA_AVAILABILITY_DRAFT.md`, the manuscript
   Data Availability statement, and the Code Availability statement matches
   the repository DOI above.
5. Upload the formal main manuscript and formal Supplementary Information
   through the journal submission system.
6. Upload `SM_Reproducibility_Guide.pdf` as the lightweight source-materials
   guide if the journal system requests a reviewer-facing PDF.

This record contains the source data, offline analysis scripts, generated report
figures, report-level source PDFs, provenance maps, checksum manifest, and a
qualitative optical-platform video supporting the associated manuscript. The
formal main manuscript and formal Supplementary Information are not included in
this repository archive and should be read separately from the journal

## Pre-Deposit Checks

Before public deposition, manually verify that the video does not reveal faces,
private account identifiers, passwords, private communications, or laboratory
information that should not be public. The included sampled-frame check did not
show faces, credentials, or local filesystem paths, but it was not a full
frame-by-frame privacy review.

The repository archive should be cited as source data/code. It should not be
described as the formal Supplementary Information file.
