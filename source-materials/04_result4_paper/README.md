# 04 Result4 Paper

Report: `report/result4_paper.pdf`

Scope: earlier Complex-B bilinear interaction report. This section covers the
four-token XOR showcase, eight-token semantic benchmark, original Complex-B
feature-family comparisons, bin-10 semantic figure variants, and compact-budget
semantic analyses.

This section is intentionally separate from `05_result4_refine_paper/`.

| --- | --- |
