# Data And Code Availability Draft

The source data, analysis code, generated report figures, provenance files, and
report-level source PDFs supporting the manuscript and formal Supplementary
Information are deposited as a public repository archive:

`SM_Source_Materials_CORE_5REPORTS/`

Repository DOI: `10.5281/zenodo.19890402`

Repository URL: `https://doi.org/10.5281/zenodo.19890402`

The archive is organized into five report-specific sections:
`01_result2_paper/`, `02_result2_refine_paper/`, `03_result3_paper/`,
`04_result4_paper/`, and `05_result4_refine_paper/`.

Each section contains its own report PDF, compact source data, offline
analysis/figure scripts, and generated figures. The earlier Result4 report and
the refined Result4 report are separated into `04_result4_paper/` and
`05_result4_refine_paper/`, respectively.

The formal main manuscript and formal Supplementary Information are not
included inside the repository archive. They should be uploaded separately
through the journal submission system and are authoritative for final text,
final figure assembly, captions, and manuscript-level claims.

Main-text data-panel source files are included under
`main_text_data_panels/` for Fig. 2d-g, Fig. 3d-f, and Fig. 4g-i. These files
map each panel to the relevant included data, script, and generated standalone
panel output. These outputs are audit replots for data/code inspection, not
exact visual copies of the final assembled manuscript panels. The package-level
relationship among the repository archive, formal SI, and main manuscript is
documented in `SM_SCOPE_AND_RELATION_TO_MANUSCRIPT_SI.md`.

Frame-level CMOS acquisition arrays for the Result4 reports are included inside
this package under `shared_raw_data/result4_frame_data/`. Hardware-control
acquisition scripts, exploratory notes, and unrelated process logs are not
included in this source-materials package.

Qualitative visual documentation of the live optical-platform interface and
witness-camera view is included at
`00_context/visual_documentation/video_qiushi.mp4`. This video documents the
physical experimental setting and is not used as quantitative evidence for any
reported result.

Before public deposition, the video should be checked manually for visible
faces, account identifiers, passwords, private communications, or laboratory
information that should not be made public.
